# TouchSkin

**TouchSkin** is a skincare shopping application designed to make browsing, discovering, and purchasing skincare products simple and convenient. The application provides an organized storefront where users can explore available products, discover featured items, and manage their shopping experience in one place.

## Features

### 🧴 Product Browsing
- Browse available skincare products with their images, descriptions, and prices.
- Explore products organized into categories.
- View product details and available stock information.

### ✨ Featured Products
- Discover selected products and promotions through the home screen's featured carousel.
- Browse promotional banners highlighting products and special selections.

### 🛒 Shopping Cart
- Add products to the shopping cart.
- Review selected items before checkout.
- Manage cart contents before placing an order.

### 📦 Order Management
- Place orders through the application.
- View order information and order status.
- Access order details for a more organized shopping experience.

### 👤 User Accounts
- Sign in to access account-related features.
- Manage personal profile information.
- Access shopping features associated with the user's account.

### 🔄 Synchronized Information
- Keep product information and featured content up to date.
- Synchronize relevant storefront information with the connected backend.
- Reflect order activity within the application's supported workflows.

## Technology Stack

- **Flutter** – Cross-platform mobile application development.
- **Dart** – Application programming language.
- **Supabase** – Backend services for authentication, data storage, and application functionality.

## Project Goal

TouchSkin aims to provide a straightforward and accessible digital shopping experience for skincare products through an organized mobile interface and integrated backend services.
